HIRESPHERE · PRIVACY

Privacy Notice

Project status: HireSphere is an academic demonstration project. Do not submit real identity documents, financial information, government ID numbers, passwords used on other websites, or other highly sensitive information.

Information the demo collects

When you create an account, HireSphere stores your name, email address, password hash, account role and the time you accepted this notice. If you complete a profile, it may also store the phone number, location, professional headline, experience, biography or company details you enter. If you apply for a job, it stores the application and any cover letter or resume you choose to submit. Employers can see the name, email address and application details you provide when you apply to their jobs.

How information is used

Information is used to provide account access, job search, applications, employer review, interview scheduling and administrative functions in this demonstration. Passwords are stored as password hashes, not as readable passwords.

Resume access

Resume files are stored outside the public website folder. A candidate can download their own resume. An employer can download a resume only for an application to a job owned by that employer. Administrators with server or database access may still be able to access stored data.

Storage and sharing

For a local college demonstration, account and job data are stored in the MySQL database configured by the project operator, and uploaded resumes are stored on the machine running the server. If the project is deployed, the hosting provider and server operator may process this information. Do not deploy this demo with real user data until a security review, access review, backup plan and retention policy are completed.

Your choices

Use test data for demonstrations. Ask the project administrator to correct or remove demo data. This version does not yet provide a self-service account deletion workflow or automatic data-retention schedule.

Security limitations

The project includes password hashing, short-lived HttpOnly session cookies, role checks, rate limits, same-origin checks, security headers and private resume downloads. These controls reduce common risks but do not guarantee security. The project has not undergone an independent penetration test, malware scanning of uploaded documents, legal compliance review or production infrastructure audit.

Contact

For this academic demo, contact the student/project administrator who operates the HireSphere instance.
